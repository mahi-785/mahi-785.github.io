# Mahi Patel's Portfolio

An interactive pixel-art portfolio. Walk around a small room, select objects to learn about me, and find hidden coins for fun facts.

**Live site:** https://mahi-785.github.io

## How to explore

- Walk with the arrow keys or WASD, or click anywhere in the room.
- Walk into an object, or click it, to open a dialogue. Choose **Yes** to see more.
- Find the 5 hidden coins to unlock fun facts.
- Prefer not to walk around? Use the buttons under the room to jump straight to any section.

## Built with

- HTML, CSS, and vanilla JavaScript in a single `index.html` file
- HTML canvas for the pixel-art room and character, drawn in code with no image files
- Breadth-first search for click-to-walk pathfinding around the furniture
- Google Fonts (VT323 and Press Start 2P)

There are no frameworks, build steps, or dependencies to install.
